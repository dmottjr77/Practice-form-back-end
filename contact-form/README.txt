SRFM Reusable Ministry Contact Form

FILES:
- index.html (iframe source)
- form.css (purple/gold glass styling)
- validate.js (client-side validation)
- send.php (IONOS-compatible PHP mail handler)

SETUP:
1. Upload folder to /contact-form/
2. Add your Google reCAPTCHA v2 site & secret keys
3. Ensure PHP mail() is enabled (IONOS default)
4. Embed using iframe:
<iframe src="/contact-form/index.html" width="100%" height="650" frameborder="0"></iframe>

This module is reusable across ministry sites.
